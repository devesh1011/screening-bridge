# Native design contract

Authority: approved v3 screens and the parent `design/screening-bridge-ios/EXPERIENCE-PLAN.md`. Surface mode: Operate.

- System typography and semantic colors, blue interactive tint, warm paper illustrations only in content.
- Native NavigationStack, toolbar Back controls, search, grouped forms, pickers, sheets and confirmation dialogs.
- System Liquid Glass styles for functional controls. No custom glass backgrounds on content cards.
- Content margin 20 pt; minimum hit target 44 pt; section spacing 24–32 pt. Text uses Dynamic Type styles.
- Programme artwork remains small enough for the next action to stay visible; decorative artwork yields space at accessibility sizes.
- One brief rationale emphasis on new sample results; immediate selection/count updates; one success response after actual local persistence.
- Custom animation respects Reduce Motion. Haptics are optional. Dark Mode and increased contrast use semantic materials/colors.
- A separate debug preview sheet exposes sample failure and appearance states without pretending to run an agent.

# Screening Bridge

Platform: native iOS, built with Xcode 27.1 and SwiftUI. iPhone-first; minimum iOS 26.

An independent cinema programmer prepares a screening, explores potential local partners, reviews collaboration ideas, and saves an editable plan. The approved v3 screen set in the parent project is the visual authority.

This milestone implements the interface using clearly labeled sample content. It includes native navigation, local draft/plan persistence, editing, selection, cancellation, recovery, animation, accessibility adaptation and optional haptics. Qloo, OpenAI, web research, authentication, outreach and ticket attribution are outside this milestone. No credentials belong in this client.

Film and partner data are fictional design fixtures except the named movie. The film artwork is original illustrative art, not an official poster. Saving a plan never sends a message.
